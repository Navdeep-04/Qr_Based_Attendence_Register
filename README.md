# 📚 QR Code Based Student Attendance Management System

This project is a **QR Code-based Student Attendance Management System** designed to automate and streamline the process of taking attendance in schools, colleges, and universities. It eliminates the need for manual attendance records by allowing students to scan QR codes, with the data being stored and analyzed automatically.

## 📌 Features

- ✅ Unique QR code generation for each student
- 📷 QR code scanning using a mobile or web camera
- 📊 Real-time attendance tracking and report generation
- 👤 Admin/Teacher panel for attendance monitoring
- 🔐 Secure login system for students and teachers
- 💾 Attendance data stored in a centralized database
- 📅 Daily, weekly, and monthly attendance reports
- 📧 Optional email alerts for low attendance
